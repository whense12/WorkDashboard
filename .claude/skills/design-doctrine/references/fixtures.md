# 검수 픽스처 (실데이터 경계로만 판정한다)

가짜 데이터('업체A', '행사1', 'Team Standup', 균일 3건)로 통과한 화면은 무효. 아래 경계를 모두 포함한 픽스처(`design/prototype/src/fixtures/sample-data.ts`)로만 렌더·테스트한다. 난수 0.

## 규모 (spec §13)
- 업체 40곳(18자 이상 이름 3곳 이상, 동명 2곳, 법인격 접두어 5종 이상), 행사 3~10개, 하루 동시 참가 25곳인 날 1일 이상, 품목 8개 이상인 업체, 첨부 20개 업체, 변경 이력 100건 업체, 일정 5,000건 규모의 월(선택).
- 예외 3개가 겹친 주, 계획 밖 고아 예외, 중첩 계획 충돌, 요일 0개 계획(무효 입력), 월 경계·연말 경계 계획.
- 오늘 기준: 0건 / 1건 / 7건(확인 필요 3) / 23건인 날을 각각 골라 위젯·Today를 확인.
