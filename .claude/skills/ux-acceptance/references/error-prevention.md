# 오류 방지 규칙 (독트린 U1–U9 실행판)

- U1 되돌릴 수 있으면 묻지 않는다: 체크·토글·단일 필드 = 즉시 저장 + 8초 undo 토스트 + Ctrl+Z. 되돌릴 수 없으면 보여주고 묻는다: 계획 편집·예외·복원·삭제·다건 변경 = preview + 영향 수 확정.
- U2 확정 버튼 = 동사+범위+수량. "확인/OK/예" 금지. 파괴적 Dialog는 취소 기본 포커스, 닫힌 뒤 포커스는 트리거로.
- U3 주 버튼을 말없이 비활성화하지 않는다: 눌리면 첫 오류 필드로 포커스 + Field validationMessage. 오류를 토스트로 알리지 않는다. 불가피한 비활성(preview 계산 전)에는 사유 한 줄.
- U4 제약 입력: 자유 텍스트 = 제목·메모·이유뿐. 날짜 DatePicker+타이핑 파싱(9/24, 0924, 2026-09-24), 시각 5분 단위(빈 값=종일), 종료<시작 자동 보정+안내, 전화 자동 하이픈, 요일 7 토글, 업체·행사 Combobox(freeform 금지), 업체명 maxlength 없음. 자연어 날짜 파싱 금지(대신 '오늘/내일/이번 금' 칩).
- U5 한글 IME: `keydown`에서 `event.isComposing || event.keyCode === 229`면 Enter/Escape 무시, `compositionend` 이후에만 확정. 단축키는 `event.code`(한/영 무관). 입력 필드 포커스 중 단문자 단축키 무시. Layer 0(no-activate)에는 입력 요소 0.
- U6 dirty 폼: Esc → 변경 없으면 닫힘, 있으면 "변경 내용을 버릴까요? [계속 편집] [버리기]". 바깥 클릭으로 닫히지 않음. Escape 사다리: 메뉴 → 플라이아웃 → 대화상자 → 인스펙터 → Layer 1 → 위젯 rest(한 단계씩); 열린 것 없는 Layer 2에서 Esc 무동작.
- U7 삭제 = soft delete + undo. 연쇄 영향(업체 → 계획 N·예외 M·첨부 K) preview.
- U8 시각 상대+절대 병기('오늘 14:30', '내일', '9/12(금)'; 인스펙터·이력·백업은 절대시각). ISO 문자열 노출 금지.
- U9 기본값은 문맥에서: Quick Add 날짜=보고 있는 날짜, 시각=다음 정시; 업체 등록 행사=현재 선택 행사, 기간=행사 기간.
- 충돌 정의(정오표): 계획 밖 고아 예외 · 같은 업체×행사 중첩 계획 · 계획 편집으로 무의미해진 예외 → 셀 마커 + 인스펙터 '충돌' 섹션 + 해결 명령.
- 클릭통과 함정: 켤 때 1회 알림 "클릭 통과 켜짐 · <단축키>로 활성화 · 트레이에서 끄기", 트레이 툴팁에 상태 상시.
- 전역 단축키 등록 실패 감지 → 설정 안내(대체 조합).
