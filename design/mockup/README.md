# 직거래 일정관리 — 정적 시안 (단계 1)

빌드·npm 설치 0. `index.html`을 **더블클릭**하면 열립니다. Windows에서 열면 서체 스택 선두의
**맑은 고딕**이 실제로 적용되어 조판을 실기로 확인할 수 있습니다(이 Linux 개발 컨테이너에는
맑은 고딕이 없어 NanumGothic으로 대체 렌더됩니다 — 화면 오른쪽 위 `렌더 서체:` 표시로 확인).

## 무엇을 보아야 하는가 (8항)

1. **위젯이 320×110 안에서 읽히는가** — 날짜 / 오늘 N / 확인 필요 N / 가장 가까운 일정 1건, 이 4개뿐입니다.
   평소 상태(rest)에 버튼·입력·아이콘 줄·테두리·그림자가 하나도 없습니다. 초 단위 시계도 없습니다.
2. **큰 글자가 화면에 하나뿐인가** — 위젯은 날짜, 인스펙터는 업체명, 캘린더는 월 이름. 나머지는 굵기와 정렬로만 구분합니다.
3. **숫자 열이 세로로 정렬되는가** — 시각·건수·날짜 전부 `tabular-nums`. 행이 바뀌어도 자릿수가 흔들리지 않아야 합니다.
4. **상태가 색 없이도 구분되는가** — 제어 막대의 `회색조` 버튼을 눌러 보세요.
   확정(채운 점) / 확인 필요(빈 링) / 이 날짜만 변경(대각선) / 불참(취소선·짧은 선) / 연결됨(가는 선)이 모양만으로 갈려야 합니다.
5. **업체명이 잘리지 않는가** — 18자 이상 업체가 3곳 있습니다. 월간·기간표에서 이름이 몇 자에서 잘리는지 봐 주세요.
6. **월간 vs 기간표** — 월간은 9월 한 달이 세로 2,400px입니다(화면 3배). 기간표는 26곳 × 31일이 한 화면에 들어갑니다.
   **업체 20곳↑ 운영에서 어느 쪽이 기본 뷰여야 하는지**가 이번 시안의 핵심 질문입니다.
7. **대화상자가 범위를 말하는가** — '계획 편집'(전체 변경)과 '이 날짜만 수정'은 제목·골격·버튼 문구가 달라야 하고,
   버튼에 영향 수(`계획 저장 · +7일 −7일`)가 적혀 있어야 합니다.
8. **방향 A / B / C 중 어느 쪽인가** — 색·서체·상태 어휘는 셋이 같고, **레이아웃·밀도·chrome 노출만** 다릅니다.
   - **A 조용한 계기** — chrome 최소, 검색·명령은 hover/focus에서만, 여백 넓게
   - **B Fluent 공간** — Fluent 관례 최대 준수, 명령 행 상시 노출, 인스펙터 상시 도킹
   - **C 스위스 운영** — 기간표 기본, compact 기본, 룰 선·정렬축 강조

## 제어 막대 (시안 전용 — 제품 UI가 아닙니다)
방향 A·B·C / 밀도 normal·compact / 테마 라이트·다크 / 액센트 ink blue·teal steel / 회색조 /
공개 리듬(켜면 클릭 1회로 위젯→오늘→캘린더 전진, Esc로 한 단계씩 후퇴).

## 이 시안이 하드코딩한 기본값 5개 — 정오표 미결 항목이므로 언제든 뒤집을 수 있습니다
| # | 기본값 | 근거 |
|---|---|---|
| ① | 주 시작 = **월요일** | `[Claude 제안]` — 정오표 G5-2 미결 |
| ② | 밀도 기본 = **normal** | 토큰 `density.default` `[Claude 제안]` |
| ③ | 위젯 '확인 필요 N' = **오늘 Task(needs_confirmation)만** | 구조적 충돌(고아 예외·중첩 계획·요일 0개)은 Layer 1 별도 섹션·인스펙터 '충돌'에서만. 둘을 합산했더니 위젯과 Layer 1 숫자가 어긋나 분리했습니다 |
| ④ | 월간 오버플로 = **9곳↑ 이고 가장 긴 이름 7자 이하일 때만 2열**, 17곳↑ 주 행 성장 + 기간표 전환 제안 | 토큰의 '9곳↑ 2열'을 그대로 쓰면 이름이 2~3자로 잘립니다(이번 달 적용 0칸) |
| ⑤ | 위젯 '가장 가까운 일정' = **1건** | spec의 '1~2건' 중 1건 |

## 단계 1이 아닌 것
동작하는 프로토타입이 아닙니다. 저장·편집·되돌리기는 화면만 있고 상태를 바꾸지 않습니다.
기능별·업무 시뮬레이션 테스트(Playwright)와 실제 상태 관리는 **단계 2**(Vite + React + Fluent UI v9)에서 합니다.
