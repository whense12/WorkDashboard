데이터로 시작한다. 제목은 결론형 한 줄뿐 — KPI 타일·통계 행 없음. 행의 열 x좌표는 모든 행에서 동일(정렬축이 상자를 대신한다). Space=체크(즉시 저장+되돌리기), Enter=인스펙터. 주 CTA는 [캘린더 열기] 하나.

Layer 2 · 캘린더 작업공간  +  Layer 3 · 인스펙터

창을 채운다(max-width 중앙 컨테이너·햄버거·페이지네이션 없음). 월간은 업체명을 직접 표시하고 +N more를 쓰지 않는다 — 존재 이유가 '누가 오는가'이므로 접기는 기능 실패다. 9곳↑ 셀 내부 2열, 17곳↑ 주 행 성장 + 기간표 전환 제안. 오늘 = 열 배경 + 날짜 Bold + 1px 상단 룰(액센트 원형 배지 아님).
