# 발견성 (조용한 위젯의 주 리스크, spec:168-174)

## 4경로 (버튼 줄 추가는 마지막 수단)
1. hover/focus reveal — 명령 슬롯을 항상 예약하고 opacity 0→1(100ms). 키보드 포커스에도 동일 노출. 레이아웃 흔들림 금지.
2. 명령 팔레트 Ctrl+K — 모든 명령 + 업체/행사/일정 검색, 한글 초성 검색(ㄱㅅ → 고성수산), 항목마다 단축키, 최근 우선.
3. 모든 메뉴 항목에 단축키 표기(MenuItem secondaryContent), 모든 아이콘 버튼 Tooltip에 단축키, `?`로 단축키 시트. 컨텍스트 메뉴는 우클릭·Shift+F10·Menu 키 동일.
4. 빈 상태·인스펙터 미선택 화면이 곧 안내: "오늘 일정 없음 · 다음 9/12(금) 고성청과", "일정 추가 Ctrl+N · 캘린더 Ctrl+2", "날짜·업체·행사를 선택하면 여기에 표시".

## 첫 사용 가이드
최초 1회 TeachingPopover 3단계(활성화 단축키 → 클릭하면 펼침/`Ctrl+N` → 트레이·기간표), 실제 요소 anchor, 건너뛰기 가능, 트레이 [도움말 다시 보기]. 모달 투어 금지.
