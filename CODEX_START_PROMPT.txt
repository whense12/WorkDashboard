Open this repository and implement the product described in AGENTS.md and CODEX_IMPLEMENTATION_BRIEF.md.

OK completes the current step and activates/calculates the next step. D-day horizon must include unlimited and custom. Vendor/work templates must be editable. The Tauri helper window must be minimal and deep-link back to the matching detail.

Desktop attachment persistence should use Tauri native app-local filesystem storage, with browser IndexedDB fallback. Preserve/migrate v5 data.

Before finishing, run the required browser/Rust/Windows checks defined in the brief.
