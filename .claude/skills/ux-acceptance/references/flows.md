# 흐름별 대본 (단계 → 화면 → 문구 → 검증)

## F1 일반 일정 등록 — Quick Add (spec:517-520)
1. 위젯 클릭 또는 전역 단축키 → Layer 1. (1)
2. `Ctrl+N` 또는 `+` → Quick Add Popover(비모달). (2)
3. 제목 입력(자유 텍스트) — 날짜 기본값=보고 있는 날짜(없으면 오늘), 시각=다음 정시, '종일' 토글. 입력 아래 해석 결과 한 줄 상시: "9월 24일(수) 14:00 · 업체 연결 없음". 업체/행사 연결은 접힌 '연결…' 한 줄(선택, Combobox).
4. Enter(조합 중 제외) → 저장 → Popover 닫힘 → 새 행 선택·포커스 → 토스트 "저장됨 · 실행 취소"(8초). `Ctrl+Enter`=저장 후 폼 유지. Esc=닫기(초안 보존).
- 검증: 위젯 기준 명령 3번 이내에 폼 도달; 제목+일시만으로 저장 가능; 해석 문장이 입력과 동기; IME 조합 중 Enter 무시; undo 후 행 소멸; 종료<시작 자동 보정 안내.

## F2 업체 등록 (spec:522-529)
순서 고정(세로 섹션, 스테퍼 아님): 기본정보(업체명·담당자·연락처·품목) → 행사 선택(Combobox, freeform 금지) → 기간(기본=행사 기간, 밖은 선택 불가) → 참가 요일(7개 토글) → 실제 참가일 preview(live: "금·토 참가 · 12일 · 첫 9/12 · 마지막 10/31" + 미니 달력 강조) → [업체 저장].
- 동명 업체: 차단 없이 인라인 경고 "같은 이름 1곳 있음 — 모노그램이 2음절로 승격됩니다" + 기존 업체 열기. 행사 없이 업체만 등록 가능.
- 요일 0개: 저장 버튼은 눌리고 요일 필드로 포커스 + "참가 요일을 1개 이상 선택".
- 검증: preview가 기간·요일 변경마다 갱신; 요약이 자동 생성(수동 입력 필드 없음); 저장 후 캘린더 해당 날짜에 이름 표시; undo 가능.

## F3 전체 일정 변경 — ParticipationPlan 편집 (spec:531-535)
진입: 인스펙터 '참가계획' [계획 편집]만(날짜 셀 컨텍스트에서는 없음). Dialog 제목 "계획 편집 — 고성수산 × 가을장터 (9/12–10/31 · 26일)".
- 편집: 기간·요일. diff preview 두 열: 추가되는 날(n) / 빠지는 날(m). 기존 Exception 충돌 목록(새 범위 밖·같은 의미가 된 예외)에 [유지]/[삭제], 선택 전 저장 불가(사유 표시). 기본 유지.
- 저장 버튼 "계획 저장 · +3일 −5일" → 토스트 undo + AuditLog.
- 검증: 날짜 셀 컨텍스트에 '계획 편집' 없음; diff 수치가 expandPlan 결과와 일치; 충돌 미선택 시 저장 불가+사유; 이력에서 되돌리기 가능.

## F4 하루만 변경 — ParticipationException (spec:537-541)
진입: 날짜 셀 → 업체 → [이 날짜만 수정](컨텍스트 메뉴·인스펙터 참가일 목록 동일 라벨). Dialog 제목 "10월 3일(금) · 고성수산 — 다른 날짜에는 영향 없음".
- 본문: 계획 상태 고스트("계획: 참가") → RadioGroup "이 날만 참가 / 이 날만 불참"(현재 상태 기본) → 이유/메모(선택) → 효과 문장 "이 날짜만 불참으로 표시됩니다. 계획은 바뀌지 않습니다". 기존 예외가 있으면 '덮어쓰기' 표시 + 이전 값. 링크 "반복 요일을 바꾸려면 계획 편집 →".
- 저장 "10/3 하루만 저장" → 캘린더 changed 마커 + 툴팁 "원래 계획: 참가 → 이 날만 불참", 선택 시 원계획 고스트.
- 검증: 계획 필드(기간·요일) 미노출; 저장 후 다른 날짜 불변; 기간표 Space가 이 대화상자를 열고 즉시 저장하지 않음.

## F5 복원 (spec:543-547)
설정/팔레트 [백업에서 복원] → 백업 목록(절대+상대 시각·크기) → 선택해도 덮어쓰지 않음 → 변경량 preview(업체/행사/계획/예외/일정 ±n, 첨부 포함 여부·누락 첨부 목록) → 문장 "현재 상태를 스냅샷으로 저장합니다" → [현재 상태를 스냅샷으로 저장하고 복원](preview 전 비활성 + 사유) → ProgressBar → MessageBar "복원됨 · 복원 취소".
- 검증: 선택만으로 데이터 불변; preview 수치; 복원 취소로 스냅샷 복귀.

## F6 행사 등록 (정오표 추가)
팔레트/캘린더 `+ 새 행사` → 행사명·기간·장소·메모 → 요약 한 줄 "가을장터 · 9/12–10/31 · 고성읍 공설운동장" → [행사 저장] → undo. 행사 기간 변경 시 소속 계획이 범위를 벗어나면 충돌 목록.

## F7 위젯 이동 / Layout Edit (spec:249-261)
Locked 기본. 트레이·컨텍스트·단축키로 편집 모드 → 1px 경계 + 핸들 + 모드 라벨 → drag 또는 방향키 1px / Shift 8px → [기본 위치] → Enter 저장 / Esc 취소·원위치 → Locked. 화면 밖 clamp. 인스펙터 pane은 왼쪽/오른쪽/하단/분리/기본 배치 명령을 컨텍스트 메뉴에 단축키와 함께.
- 검증: Locked에서 drag 불가; 방향키 이동; Esc 원위치; 기본 위치 복귀.

## 공통 검증(모든 흐름)
- 키보드만으로 진입·완료·복귀. Esc 사다리 한 단계씩. 포커스가 떠난 자리로 복귀.
- 문구: 상태 5어휘 고정, 버튼은 동사+범위+수량, 요약은 결론형.
- 빈/로딩/오류/충돌 상태 1개 이상 렌더.
